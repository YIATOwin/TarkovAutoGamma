# TarkovAutoGamma

面向塔科夫的独立自动调色工具。把画面分为九个区域，以中央区域为重点判断暗部亮度，联动调整 Gamma、亮度和对比度。

**[下载 Windows x64 预览版](https://github.com/YIATOwin/TarkovAutoGamma/releases/tag/v0.2.0)**

## 快速开始

1. 下载 `TarkovAutoGamma-win-x64.zip` 并解压，运行 `TarkovAutoGamma.exe`。无需安装 .NET，不需要管理员权限。
2. 关闭系统 HDR / 自动 HDR，暂时退出 Gamma Panel 等其他色彩调整工具。
3. 选择游戏所在显示器，保留默认的「仅游戏前台」，点击「开启」。
4. 回到游戏。切出游戏会恢复开启前的显示曲线；切回所选显示器上的游戏后重新采样和平滑调整。
5. 需要后台运行时点击「收起」。关闭窗口会停止并退出。

默认值：**Gamma 1.60、亮度 +6、对比度 +8、总强度 60%、5 次/秒、中心权重 40%、过渡 300ms**。控制项上的说明移到了悬停提示；检测频率、中心权重和过渡时间在「更多」里。

## 原图 / 效果预览

- 默认显示内置的暗处、亮窗和灰阶样图；拖动分界线比较同一位置，或使用左右方向键、Home / End。
- 「载入截图」支持本机 PNG / JPEG / BMP，文件最大 40MB。图片只用于本机预览，不上传，不复制进发布包。
- 调整左侧滑块，右侧会根据这张图计算并显示最终建议效果；底部显示该图对应的实际 Gamma、亮度和对比度幅度。
- 为防止显示器曲线与图片模拟叠加，**本窗口在前台时始终暂停硬件调整并恢复原始颜色**，即使取消了「仅游戏前台」。切回游戏后再继续。
- 预览只保留一组缩小后的原图和效果图，最高 960×540；更换图片后释放旧图。它不包含显示器校准、驱动及游戏输出的所有差异，实际游戏观感仍需确认。

## 按键与设置

| 设置 / 按键 | 说明 |
| --- | --- |
| Ctrl+Alt+F9 | 开启 / 停止自动调整 |
| Ctrl+Alt+F10 | 停止并立即请求恢复原始颜色 |
| 总强度 | 同时控制三项自动幅度；0% 保持原始曲线 |
| Gamma | 自动提亮上限，范围 1.00–2.00，实际值受画面与总强度约束 |
| 亮度 | 柔和亮度补偿 -20～+20；0 不补偿，保留黑白端点 |
| 对比度 | S 曲线对比度 -30～+30；正值增强明暗层次，负值柔化，0 不额外调整 |
| 检测频率 | 2 / 5 / 10 次/秒；采样频率不等于游戏帧率 |
| 中心区域权重 | 20% / 40% / 60%；剩余权重分给四边和四角，边缘中点权重为角落的两倍 |
| 过渡 ms | 默认约 300ms 到达新目标；目标变化会从当前状态重新衔接，显卡写入延迟可能延长实际耗时 |
| 仅游戏前台 | 根据前台进程名 `EscapeFromTarkov` 及所在显示器判断；关闭后也始终排除本工具窗口前台 |

快捷键被其他程序占用时会在窗口提示，仍可通过窗口或托盘操作。所有偏好会保留，但每次启动都保持**未开启**。

## 工作方式

`Windows 桌面复制 → GPU 缩小为 320×180 → 九区域加权直方图 → 暗部/高光判断 → 三项同步过渡 → 合成原始 RGB 曲线`

- 原始全屏纹理保留在 GPU 上，CPU 只读回约 225KiB 的缩小图；排除部分外框和底部 HUD，减少界面对统计的干扰。
- 明亮画面接近原始曲线；暗处按设置逐渐提亮；近黑画面和疑似绿色夜视画面回落至原始曲线。夜视判断是简单颜色启发式，可能误判绿色场景。
- 用原有 RGB 曲线进行映射，保留开启时的显示校准；不将每次调整后的结果当作新基线。
- Gamma 为主，亮度进行柔和补偿，对比度用保留端点的 S 曲线加强层次。三项合成一次写入，采集次数不变；这些数值并不与 Gamma Panel 的同名参数逐项等价。
- 对小幅波动设置死区；只在曲线确有变化时写入。短过渡期间请求频率最多约每秒 20 次，稳定后跳过相同曲线。
- Gamma 提亮作用于所选显示器的整体输出。它不修改游戏材质、光照或雾效，也不是局部锐化/着色器滤镜。

参考了 [TarkovAutoShade](https://github.com/lu1249765686/TarkovAutoShade) 使用 Windows Gamma Ramp 调整显示输出的方式；本项目的实时采集、九区域分析、界面与恢复逻辑独立实现。

## 颜色恢复

- 切出游戏：恢复基线并释放采集资源；切回后重建采集。
- 打开本工具调整预览：同样恢复基线，避免对比图被二次调色。
- 停止、正常退出、锁屏、休眠、显示配置变化：停止或恢复。显示配置改变后需要手动重新开启。
- 修改颜色前先把原始曲线写入本地恢复记录。
- 开启时启动独立恢复保护进程。主进程被强制结束后，它会尝试恢复原曲线；正常停止后保护进程退出。
- 若恢复失败，记录会保留，下一次启动会先尝试恢复。驱动失效、硬件断连等情况下无法保证立即恢复。

任务管理器中运行时可能看到两个同名进程，第二个是恢复保护进程，也会占用少量 CPU/内存。不要把它当成重复启动的界面进程。

## 支持范围和当前限制

- 首版面向 Windows 11 x64、横向 SDR 显示器、无边框游戏；单次只选择一台显示器。
- HDR / 自动 HDR 不支持。系统报告所选输出为非标准 SDR 色彩空间时，会停止调整。
- Windows Gamma 接口受驱动、系统色彩管理和其他应用影响，可能返回成功却未真正生效。工具在明显提亮后进行曲线回读核对；不符合目标时停止并恢复。回读核对也不能代替肉眼确认最终显示效果。
- 原型中的亮度保护尚未针对菜单、闪光弹、瞄准镜和所有天气逐一调校；这些情况也可能影响自动建议。
- 不与其他 Gamma 工具同时使用。开启后若更改显示器校准，请先停止本工具。
- 早期采集诊断仅测量采集和分析；本工具增加了实际 Gamma 写入、界面及保护进程，不能把早期诊断的 CPU/内存数字直接当成最终占用。

相关 Windows 接口限制见 [微软说明](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp)。本工具不读取游戏内存，不注入游戏，不修改游戏文件。

## 数据与问题反馈

程序不联网，不保存游戏截图或视频，不自动上传数据。设置、恢复记录和错误日志保存在：

`%LocalAppData%\TarkovAutoGamma`

可以从窗口底部打开该目录。反馈时请说明显卡、分辨率、游戏显示模式、滤镜设置，以及室内/室外效果；若有错误，可附 `errors.log`。日志可能含本机路径，公开提交前可自行检查。

## 从源码构建

需要 Windows 和 .NET 10 SDK。执行：

```powershell
dotnet run --project tests/Regression.csproj -c Release
./scripts/build.ps1
```

产物在 `artifacts/win-x64`。本地 SDK 可通过 `./scripts/build.ps1 -Dotnet '完整路径/dotnet.exe'` 指定。

`--native-test 输出目录` 是开发验证入口，会临时写入轻度的三项组合曲线，再验证正常恢复、强制结束后的保护恢复和实际采集，测试结束恢复基线。它会改变当前显示输出，请只在明确准备进行显示测试时使用。

升级到 0.2 时，旧版默认的 1200ms 会迁移为 300ms；手动修改过的其他过渡值会保留。点击「重置」可统一恢复新默认值。
